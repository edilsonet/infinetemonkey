# Canon: anac-legislacao

This folder is the canon layer for `anac-legislacao`. Canon here is retrieval doctrine
over the ANAC corpus. It is not a copy of any RBAC, IS, or IAC.

This README is navigational. The substantive node is [[anac-legislacao-core-doctrine]].

## What canon means here

- Compressed synthesis of how an agent must retrieve Brazilian aviation rules.
- Fragments in `support/` are the statute text. Canon says how to use them.
- Small relative to the corpus: three files, not hundreds of sections.

## What canon is not

- Not the legal corpus. That lives in `support/extracted/` and `support/fragments/`.
- Not a substitute for reading the cited subsection.
- Not a public export.
